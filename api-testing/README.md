# API-тестирование Demoblaze

## Описание
Коллекция Postman для тестирования API сайта Demoblaze.
Содержит позитивные и негативные сценарии для проверки основных эндпоинтов.

## Используемые инструменты
- Postman
- DevTools

## Содержание коллекции

### Positive Tests
| Запрос | Эндпоинт | Проверяет |
|--------|----------|-----------|
| Login | POST /login | Успешный вход, получение токена |
| Add To Cart | POST /addtocart | Добавление товара в корзину |
| View Cart | POST /viewcart | Просмотр содержимого корзины |

### Negative Tests
| Запрос | Эндпоинт | Проверяет |
|--------|----------|-----------|
| Wrong Password | POST /login | Ошибка при неверном пароле |
| Failed Sign Up | POST /signup | Ошибка при регистрации существующего пользователя |

## Анализ тестового покрытия

В ходе работы был проведен анализ API тестируемого приложения Demoblaze. 

**Особенности API:**
1. **Архитектура:** Все эндпоинты (`/login`, `/signup`, `/addtocart`, `/viewcart`) используют только метод **POST**. Это архитектурное решение, вероятно, принято для упрощения обработки данных в рамках учебного проекта
2. **Некорректные статус-коды:** API всегда возвращает статус **200 OK**, даже при возникновении ошибок (неверный пароль, отсутствие пользователя)
3. **Структура ответов:** Ответы имеют неоднородную структуру. Например, эндпоинт `/addtocart` возвращает пустое тело, в то время как `/viewcart` возвращает структурированный JSON-массив
