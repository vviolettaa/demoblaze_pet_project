# Чек-лист: Категории товаров

## Позитивные сценарии
- [ ] Отображение товаров категории "Phones" при клике на соответствующую кнопку
- [ ] Отображение товаров категории "Laptops" при клике на соответствующую кнопку
- [ ] Отображение товаров категории "Monitors" при клике на соответствующую кнопку
- [ ] Отображение всех товаров при клике на кнопку "Home" 
- [ ] Каждый товар в категории отображается с названием и ценой
- [ ] При клике на товар открывается его карточка с детальным описанием
- [ ] Работа пагинации (кнопки "Next" и "Previous") в категории "Phones"
- [ ] Работа пагинации (кнопки "Next" и "Previous") в категории "Laptops"
- [ ] Работа пагинации (кнопки "Next" и "Previous") в категории "Monitors"

## Проверки интерфейса
- [ ] Категории отображаются в левой боковой панели
- [ ] Активная категория визуально выделяется (например, цветом)
- [ ] При переключении категорий обновляется список товаров без перезагрузки страницы
- [ ] В каждой категории отображается корректное количество товаров
- [ ] Цены товаров в разных категориях отображаются в одинаковом формате
- [ ] Пагинация работает корректно (кнопки "Previous"/"Next" активны/неактивны в зависимости от страницы)
- [ ] При переходе на следующую страницу отображаются следующие товары
