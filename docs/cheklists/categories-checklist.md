## Проверки интерфейса
- [x] Категории отображаются в левой боковой панели
- [ ] Активная категория визуально выделяется (например, цветом) [БАГ-002](../bug-reports/bug-002-category-highlight.md)
- [x] При переключении категорий обновляется список товаров без перезагрузки страницы
- [x] Цены товаров в разных категориях отображаются в одинаковом формате
- [ ] Пагинация работает корректно (кнопки "Previous"/"Next" активны/неактивны в зависимости от страницы) [БАГ-003](../bug-reports/bug-003-pagination-show-wrong-items.md)
