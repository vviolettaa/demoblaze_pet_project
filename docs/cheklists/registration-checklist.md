# Чек-лист: Регистрация

## Позитивные сценарии
- [x] Успешная регистрация с уникальным логином и паролем
- [x] После регистрации появляется Alert с сообщением "Sign up successful."
- [x] Новый пользователь может авторизоваться после регистрации

## Негативные сценарии
- [x] Регистрация с уже существующим логином (Alert: "This user already exist.")
- [x] Регистрация с пустым полем Username (пароль заполнен)
- [x] Регистрация с пустым полем Password (логин заполнен)
- [x] Регистрация с пустыми полями Username и Password
- [ ] Регистрация с логином, содержащим только пробелы [БАГ-011](../bug-reports/bug-011-registration-username-only-spaces.md)
- [ ] Регистрация с паролем менее 4 символов [БАГ-012](../bug-reports/bug-012-registration-password-too-short.md)
- [ ] Регистрация с паролем, содержащим только пробелы [БАГ-013](../bug-reports/bug-013-registration-password-only-spaces.md)

## Проверки интерфейса
- [x] Модальное окно регистрации открывается по клику на "Sign up"
- [x] Поле Password скрывает вводимые символы (звёздочки)
- [x] Есть кнопка закрытия модального окна (X)
- [x] Модальное окно закрывается при клике вне его области
- [x] При успешной регистрации Alert содержит корректное сообщение
- [x] При ошибке Alert содержит понятное сообщение об ошибке
