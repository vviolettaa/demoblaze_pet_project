# Чек-лист: Регистрация

## Позитивные сценарии
- [ ] Успешная регистрация с уникальным логином и паролем
- [ ] После регистрации появляется Alert с сообщением "Sign up successful."
- [ ] Новый пользователь может авторизоваться после регистрации

## Негативные сценарии
- [ ] Регистрация с уже существующим логином (Alert: "This user already exist.")
- [ ] Регистрация с пустым полем Username (пароль заполнен)
- [ ] Регистрация с пустым полем Password (логин заполнен)
- [ ] Регистрация с пустыми полями Username и Password
- [ ] Регистрация с логином, содержащим только пробелы
- [ ] Регистрация с паролем менее 4 символов
- [ ] Регистрация с паролем, содержащим только пробелы

## Проверки интерфейса
- [ ] Модальное окно регистрации открывается по клику на "Sign up"
- [ ] Поле Password скрывает вводимые символы (звёздочки)
- [ ] Есть кнопка закрытия модального окна (X)
- [ ] Модальное окно закрывается при клике вне его области
- [ ] При успешной регистрации Alert содержит корректное сообщение
- [ ] При ошибке Alert содержит понятное сообщение об ошибке
