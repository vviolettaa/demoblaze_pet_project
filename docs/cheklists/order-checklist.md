# Чек-лист: Оформление заказа

## Позитивные сценарии
- [ ] Успешное оформление заказа с заполненными валидными данными
- [ ] После успешного заказа появляется сообщение "Thank you for your purchase!"
- [ ] В сообщении о покупке отображается ID заказа
- [ ] После закрытия Alert корзина очищается

## Негативные сценарии
- [ ] Оформление заказа с пустыми полями (Name, Country, City, Credit Card, Month, Year)
- [ ] Оформление заказа с пустым полем Name
- [ ] Оформление заказа с пустым полем Country
- [ ] Оформление заказа с пустым полем City
- [ ] Оформление заказа с пустым полем Credit Card
- [ ] Оформление заказа с пустым полем Month
- [ ] Оформление заказа с пустым полем Year
- [ ] Оформление заказа с невалидным номером кредитной карты
- [ ] Оформление заказа с невалидным месяцем (например, 13)
- [ ] Оформление заказа с невалидным годом (например, 2000)

## Проверки интерфейса
- [ ] Модальное окно заказа открывается по кнопке "Place Order"
- [ ] Все поля ввода видны и активны
- [ ] Поле Credit Card скрывает вводимые символы (если предусмотрено)
- [ ] Кнопка "Purchase" активна при открытом модальном окне
- [ ] Кнопка "Close" закрывает модальное окно без оформления заказа
- [ ] Модальное окно закрывается при клике вне его области
- [ ] После успешного заказа показывается Alert с суммой и ID заказа
- [ ] Alert содержит корректное сообщение об ошибке при невалидных данных
