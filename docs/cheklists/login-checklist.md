# Чек-лист: Авторизация

## Позитивные сценарии
- [x] Успешная авторизация с валидными логином и паролем
- [x] После авторизации в верхнем меню отображается имя пользователя
- [x] Кнопка Log Out появляется после входа
- [x] При нажатии Log Out происходит выход из системы

## Негативные сценарии
- [x] Авторизация с пустым полем Username (пароль заполнен)
- [x] Авторизация с пустым полем Password (логин заполнен)
- [x] Авторизация с пустыми полями Username и Password
- [x] Авторизация с неверным логином (пароль верный)
- [x] Авторизация с неверным паролем (логин верный)
- [x] Авторизация с неверными логином и паролем

## Проверки интерфейса
- [x] Модальное окно авторизации открывается по клику на "Log in"
- [x] Поле Password скрывает вводимые символы (звёздочки)
- [x] Есть кнопка закрытия модального окна (X)
- [x] Модальное окно закрывается при клике вне его области
