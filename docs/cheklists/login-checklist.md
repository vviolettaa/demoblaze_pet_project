# Чек-лист: Авторизация

## Позитивные сценарии
- [ ] Успешная авторизация с валидными логином и паролем
- [ ] После авторизации в верхнем меню отображается имя пользователя
- [ ] Кнопка Log Out появляется после входа
- [ ] При нажатии Log Out происходит выход из системы

## Негативные сценарии
- [ ] Авторизация с пустым полем Username (пароль заполнен)
- [ ] Авторизация с пустым полем Password (логин заполнен)
- [ ] Авторизация с пустыми полями Username и Password
- [ ] Авторизация с неверным логином (пароль верный)
- [ ] Авторизация с неверным паролем (логин верный)
- [ ] Авторизация с неверными логином и паролем
- [ ] Авторизация с логином, содержащим спецсимволы

## Проверки интерфейса
- [ ] Модальное окно авторизации открывается по клику на "Log in"
- [ ] Поле Password скрывает вводимые символы (звёздочки)
- [ ] Есть кнопка закрытия модального окна (X)
- [ ] Модальное окно закрывается при клике вне его области
