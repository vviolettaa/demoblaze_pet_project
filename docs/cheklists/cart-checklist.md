# Чек-лист: Корзина

## Позитивные сценарии
- [x] Добавление товара в корзину с карточки товара
- [x] Добавление нескольких разных товаров в корзину (например, телефон и ноутбук)
- [x] Отображение добавленных товаров в корзине с правильными названиями и ценами
- [x] Удаление товара из корзины по кнопке "Delete"
- [x] Переход к оформлению заказа по кнопке "Place Order"

## Негативные сценарии
- [ ] Попытка оформить заказ с пустой корзиной - [БАГ-001](../bug-reports/bug-001-empty-cart-order.md)

## Проверки интерфейса
- [x] В корзине отображается общая сумма всех товаров
- [x] Цена товара в корзине совпадает с ценой в каталоге
- [x] Кнопка "Place Order" активна при наличии товаров в корзине
- [x] Кнопка "Delete" работает для каждого товара отдельно
