# Чек-лист: Корзина на Demoblaze

## Позитивные сценарии
- [ ] Добавление товара в корзину с карточки товара
- [ ] Добавление нескольких разных товаров в корзину (например, телефон и ноутбук)
- [ ] Отображение добавленных товаров в корзине с правильными названиями и ценами
- [ ] Удаление товара из корзины по кнопке "Delete"
- [ ] Переход к оформлению заказа по кнопке "Place Order"
- [ ] Возврат к покупкам из корзины (кнопка "Continue Shopping")

## Негативные сценарии
- [ ] Попытка оформить заказ с пустой корзиной

## Проверки интерфейса
- [ ] В корзине отображается общая сумма всех товаров
- [ ] Количество товаров в корзине отображается в иконке корзины (если есть)
- [ ] Цена товара в корзине совпадает с ценой в каталоге
- [ ] Кнопка "Place Order" активна при наличии товаров в корзине
- [ ] Кнопка "Delete" работает для каждого товара отдельно
- [ ] При удалении всех товаров корзина становится пустой
