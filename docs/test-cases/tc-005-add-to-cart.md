# TC-005: Добавление товара в корзину

| Поле | Значение |
|------|----------|
| **ID** | TC-005 |
| **Название** | Добавление товара в корзину с карточки товара |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | Пользователь авторизован в системе |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. В категории "Phones" выбрать любой товар <br>3. В карточке товара нажать кнопку "Add to cart"<br>4. Дождаться появления Alert<br>5. Нажать "OK" в Alert<br>6. Перейти в корзину (кнопка "Cart" в верхнем меню) |
| **Ожидаемый результат** | 1. Появляется Alert с сообщением "Product added"<br>2. В корзине отображается добавленный товар с правильным названием и ценой |
| **Фактический результат** | Alert "Product added" появился. В корзине отображается добавленный товар с правильным названием и ценой. Результат соответствует ожидаемому |
| **Статус** | Passed |
