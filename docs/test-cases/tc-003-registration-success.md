# TC-003: Успешная регистрация нового пользователя

| Поле | Значение |
|------|----------|
| **ID** | TC-003 |
| **Название** | Успешная регистрация нового пользователя с уникальными данными |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | Пользователь с таким логином не зарегистрирован в системе |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Sign up" в верхнем меню<br>3. В поле "Username" ввести уникальный логин <br>4. В поле "Password" ввести пароль <br>5. Нажать кнопку "Sign up" |
| **Ожидаемый результат** | Появляется Alert с сообщением "Sign up successful" |
| **Фактический результат** | Появился Alert с сообщением "Sign up successful", новый пользователь успешно зарегистрирован. Результат соответствует ожидаемому |
| **Статус** | Passed |
