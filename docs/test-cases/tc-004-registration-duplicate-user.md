# TC-004: Регистрация с уже существующим логином

| Поле | Значение |
|------|----------|
| **ID** | TC-004 |
| **Название** | Регистрация с логином, который уже зарегистрирован в системе |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | В системе уже зарегистрирован пользователь с логином "viachhtest" |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Sign up" в верхнем меню<br>3. В поле "Username" ввести "viachhtest"<br>4. В поле "Password" ввести любой пароль<br>5. Нажать кнопку "Sign up" |
| **Ожидаемый результат** | Появляется Alert с сообщением "This user already exist" |
| **Фактический результат** | Появился Alert с сообщением "This user already exist", система не зарегистрировала нового пользователя с существующим логином. Результат соответствует ожидаемому |
| **Статус** | Passed |
