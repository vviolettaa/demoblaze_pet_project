# TC-009: Удаление товара из корзины

| Поле | Значение |
|------|----------|
| **ID** | TC-009 |
| **Название** | Удаление товара из корзины по кнопке "Delete" |
| **Приоритет** | P1 (Высокий) |
| **Предусловие** | 1. Пользователь авторизован в системе<br>2. В корзине есть хотя бы один товар |
| **Шаги** | 1. Перейти в корзину (кнопка "Cart" в верхнем меню)<br>2. Найти добавленный товар в списке<br>3. Нажать кнопку "Delete" рядом с этим товаром |
| **Ожидаемый результат** | 1. Товар удаляется из корзины<br>2. Корзина становится пустой (если товар был единственный)<br>3. Сообщение об успешном удалении отсутствует (товар просто исчезает)<br>4. Сумма заказа обновляется |
| **Фактический результат** | Фактический результат соответствует ожидаемому |
| **Статус** | Passed |
