# TC-006: Успешное оформление заказа

| Поле | Значение |
|------|----------|
| **ID** | TC-006 |
| **Название** | Успешное оформление заказа с валидными данными |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | 1. Пользователь авторизован в системе<br>2. В корзине есть хотя бы один товар |
| **Шаги** | 1. Перейти в корзину (кнопка "Cart")<br>2. Нажать кнопку "Place Order"<br>3. В модальном окне заполнить поля:<br>&nbsp;&nbsp;- Name: "Test User"<br>&nbsp;&nbsp;- Country: "Russia"<br>&nbsp;&nbsp;- City: "Moscow"<br>&nbsp;&nbsp;- Credit Card: "1234567890123456"<br>&nbsp;&nbsp;- Month: "12"<br>&nbsp;&nbsp;- Year: "2028"<br>4. Нажать кнопку "Purchase" |
| **Ожидаемый результат** | 1. Появляется Alert с сообщением "Thank you for your purchase!"<br>2. В Alert отображается ID заказа<br>3. В Alert отображается сумма заказа<br>4. Корзина очищается после закрытия Alert |
| **Фактический результат** | Фактический результат соответствует ожидаемому |
| **Статус** | Passed |
