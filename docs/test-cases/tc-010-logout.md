# TC-011: Выход из системы (Log Out)

| Поле | Значение |
|------|----------|
| **ID** | TC-011 |
| **Название** | Успешный выход из системы по кнопке "Log out" |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | Пользователь авторизован в системе (логин: testuser) |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. Убедиться, что пользователь авторизован (в меню отображается "Welcome testuser")<br>3. Нажать кнопку "Log out" в верхнем меню<br>4. Дождаться перезагрузки страницы |
| **Ожидаемый результат** | 1. Кнопка "Log out" исчезает<br>2. Появляется кнопка "Log in"<br>3. Имя пользователя больше не отображается в меню<br>4. Пользователь разлогинен (сессия завершена) |
| **Фактический результат** | |
| **Статус** | Не выполнен |
