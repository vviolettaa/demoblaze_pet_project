# TC-012: Оформление заказа с пустым полем Name

| Поле | Значение |
|------|----------|
| **ID** | TC-011 |
| **Название** | Оформление заказа с пустым полем Name |
| **Приоритет** | P1 (Высокий) |
| **Предусловие** | 1. Пользователь авторизован в системе<br>2. В корзине есть хотя бы один товар |
| **Шаги** | 1. Перейти в корзину (кнопка "Cart")<br>2. Нажать кнопку "Place Order"<br>3. Заполнить поля, кроме поля "Name":<br>&nbsp;&nbsp;- Name: (оставить пустым)<br>&nbsp;&nbsp;- Country: "Russia"<br>&nbsp;&nbsp;- City: "Moscow"<br>&nbsp;&nbsp;- Credit Card: "1234567890123456"<br>&nbsp;&nbsp;- Month: "12"<br>&nbsp;&nbsp;- Year: "2028"<br>4. Нажать кнопку "Purchase" |
| **Ожидаемый результат** | Система не должна оформлять заказ. Должна появляться ошибка валидации с требованием заполнить поле Name. |
| **Фактический результат** | |
| **Статус** | Не выполнен |
