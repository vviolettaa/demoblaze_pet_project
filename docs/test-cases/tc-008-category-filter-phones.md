# TC-008: Фильтрация товаров по категории "Phones"

| Поле | Значение |
|------|----------|
| **ID** | TC-008 |
| **Название** | Отображение только товаров категории "Phones" при клике на соответствующую кнопку |
| **Приоритет** | P1 (Высокий) |
| **Предусловие** | Открыта главная страница Demoblaze |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. В левой боковой панели нажать на категорию "Phones"<br>3. Дождаться обновления списка товаров |
| **Ожидаемый результат** | 1. В списке отображаются только товары из категории "Phones"<br>2. Товары из других категорий (Laptops, Monitors) не отображаются<br>3. У каждого товара отображается название и цена<br>4. Категория "Phones" визуально выделена как активная |
| **Фактический результат** | |
| **Статус** | Не выполнен |
