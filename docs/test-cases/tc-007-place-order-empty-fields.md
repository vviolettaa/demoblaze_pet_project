# TC-007: Оформление заказа с пустыми полями

| Поле | Значение |
|------|----------|
| **ID** | TC-007 |
| **Название** | Оформление заказа с пустыми полями в модальном окне |
| **Приоритет** | P1 (Высокий) |
| **Предусловие** | 1. Пользователь авторизован в системе<br>2. В корзине есть хотя бы один товар |
| **Шаги** | 1. Перейти в корзину (кнопка "Cart")<br>2. Нажать кнопку "Place Order"<br>3. В модальном окне оставить все поля пустыми<br>4. Нажать кнопку "Purchase" |
| **Ожидаемый результат** | Система не должна оформлять заказ. Должна появляться ошибка валидации с требованием заполнить обязательные поля. |
| **Фактический результат** | Появился Alert с сообщением "Please fill out Name and Creditcard". Система не пропускает заказ, но сообщение об ошибке указывает только на два поля (Name и Creditcard), хотя все поля (Country, City, Month, Year) также были пустыми и являются важными при оформлении заказа |
| **Статус** | Failed [БАГ-014](../bug-reports/bug-014-incomplete-validation-message.md) |
