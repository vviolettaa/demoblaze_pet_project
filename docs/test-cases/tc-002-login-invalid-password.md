# TC-002: Авторизация с неверным паролем

| Поле | Значение |
|------|----------|
| **ID** | TC-002 |
| **Название** | Авторизация с неверным паролем |
| **Приоритет** | P0 (Критичный) |
| **Предусловие** | Пользователь зарегистрирован в системе (логин: testuser, пароль: Test1234) |
| **Шаги** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Log in" в верхнем меню<br>3. В поле "Username" ввести "testuser"<br>4. В поле "Password" ввести "WrongPassword"<br>5. Нажать кнопку "Log in" |
| **Ожидаемый результат** | Появляется Alert с сообщением "Wrong password." или "User does not exist." |
| **Фактический результат** | |
| **Статус** | Не выполнен |
