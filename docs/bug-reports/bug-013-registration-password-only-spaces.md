# БАГ-013: Регистрация с паролем, содержащим только пробелы

| Поле | Значение |
|------|----------|
| **ID** | BUG-013 |
| **Название** | Регистрация с паролем, содержащим только пробелы |
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Регистрация |
| **Шаги воспроизведения** | 1. Открыть Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Sign up" в верхнем меню<br>3. В поле "Username" ввести валидный логин <br>4. В поле "Password" ввести только пробелы <br>5. Нажать кнопку "Sign up" |
| **Фактический результат** | Регистрация успешна, появляется Alert с сообщением "Sign up successful" |
| **Ожидаемый результат** | Появляется сообщение об ошибке: "Пароль не может быть пустым или состоять только из пробелов" |
