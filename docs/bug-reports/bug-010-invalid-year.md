# БАГ-010: Оформление заказа с невалидным годом

| Поле | Значение |
|------|----------|
| **ID** | BUG-010 |
| **Название** | Оформление заказа с невалидным годом |
| **Приоритет** | Medium |
| **Серьёзность** | Normal |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Корзина |
| **Шаги воспроизведения** | 1. Открыть Demoblaze (https://www.demoblaze.com/)<br>2. Добавить любой товар в корзину<br>3. Перейти в корзину и нажать "Place Order"<br>4. Заполнить все поля валидными данными, кроме поля "Year" (ввести "2000")<br>5. Нажать "Purchase" |
| **Фактический результат** | Заказ успешно оформляется, появляется сообщение "Thank you for your purchase!" |
| **Ожидаемый результат** | Система должна выдать сообщение об ошибке с требованием ввести корректный год перед оформлением заказа |
