# БАГ-011: Регистрация с логином, содержащим только пробелы

| Поле | Значение |
|------|----------|
| **ID** | BUG-011 |
| **Название** | Регистрация с логином, содержащим только пробелы |
| **Приоритет** | Medium |
| **Серьёзность** | Normal |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Регистрация |
| **Шаги воспроизведения** | 1. Открыть Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Sign up" в верхнем меню<br>3. В поле "Username" ввести только пробелы<br>4. В поле "Password" ввести валидный пароль<br>5. Нажать кнопку "Sign up" |
| **Фактический результат** | Регистрация успешна, появляется Alert с сообщением "Sign up successful" |
| **Ожидаемый результат** | Появляется сообщение об ошибке: "Логин не может состоять только из пробелов" |
