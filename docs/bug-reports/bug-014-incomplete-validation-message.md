# БАГ-014: Неполное сообщение об ошибке валидации при пустых полях заказа

| Поле | Значение |
|------|----------|
| **ID** | BUG-014 |
| **Название** | Неполное сообщение об ошибке валидации при пустых полях в форме заказа |
| **Приоритет** | Medium |
| **Серьёзность** | Normal |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 |
| **Компонент** | Корзина |
| **Шаги воспроизведения** | 1. Открыть Demoblaze (https://www.demoblaze.com/)<br>2. Авторизоваться с валидными данными<br>3. Добавить любой товар в корзину<br>4. Перейти в корзину и нажать "Place Order"<br>5. Оставить все поля пустыми<br>6. Нажать "Purchase" |
| **Фактический результат** | Появился Alert с сообщением: "Please fill out Name and Creditcard". Ошибка указывает только на два поля, хотя все поля (Country, City, Month, Year) также пустые и являются важными при оформлении заказа |
| **Ожидаемый результат** | Сообщение об ошибке должно информировать о необходимости заполнить все поля (Name, Country, City, Credit Card, Month, Year) или хотя бы корректно указывать на все пустые поля |
