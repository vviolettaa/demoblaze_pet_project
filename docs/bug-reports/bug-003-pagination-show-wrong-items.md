# БАГ-003: При нажатии на пагинацию в конце списка отображаются товары из других категорий

| Поле | Значение |
|------|----------|
| **ID** | BUG-003 |
| **Название** | При нажатии на пагинацию в конце списка отображаются товары из других категорий |
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Окружение** | Windows 11, Яндекс.Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Пагинация |
| **Шаги воспроизведения** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. В левой боковой панели выбрать категорию с небольшим количеством товаров <br>3. Нажать кнопку "Next" для перехода на следующую страницу (даже если товары закончились)<br>4. Обратить внимание на отобразившийся список товаров |
| **Фактический результат** | Кнопка "Next" активна, несмотря на то, что в категории больше нет товаров. При нажатии на "Next" отображается случайный список товаров (в том числе из других категорий). При нажатии на "Previous" также отображается некорректный список |
| **Ожидаемый результат** | 1. Кнопка "Next" должна быть неактивной (серой или скрытой), когда достигнут конец списка товаров в выбранной категории<br>2. При отсутствии товаров на следующей странице не должны подгружаться товары из других категорий<br>3. Пагинация должна работать только в пределах выбранной категории |
