# БАГ-002: Отсутствует визуальное выделение активной категории

| Поле | Значение |
|------|----------|
| **ID** | BUG-002 |
| **Название** | Активная категория товаров не выделяется визуально после клика |
| **Приоритет** | Low |
| **Серьёзность** | Minor |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Каталог товаров |
| **Шаги воспроизведения** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. В левой боковой панели нажать на категорию "Phones"<br>3. Обратить внимание на внешний вид кнопки "Phones" после клика<br>4. Нажать на категорию "Laptops"<br>5. Обратить внимание на внешний вид кнопки "Laptops" после клика |
| **Фактический результат** | После клика на категорию визуальное состояние кнопки не меняется. Все категории выглядят одинаково, невозможно определить, какая категория активна в данный момент |
| **Ожидаемый результат** | Активная категория должна визуально выделяться, например: другим цветом фона, подчёркиванием, жирным шрифтом или изменением цвета текста |
