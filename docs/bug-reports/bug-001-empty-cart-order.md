# БАГ-001: Оформление заказа с пустой корзиной

| Поле | Значение |
|------|----------|
| **ID** | BUG-001 |
| **Название** | Возможность открытия модального окна оформления заказа при пустой корзине |
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Корзина |
| **Шаги воспроизведения** | 1. Открыть главную страницу Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Cart" в верхнем меню<br>3. Убедиться, что корзина пуста (не добавлять товары)<br>4. Нажать кнопку "Place Order" |
| **Фактический результат** | Открывается модальное окно оформления заказа с пустыми полями, доступное для заполнения |
| **Ожидаемый результат** | Система не должна открывать модальное окно оформления заказа при пустой корзине. Должно появляться сообщение: "Корзина пуста. Добавьте товары для оформления заказа." |
