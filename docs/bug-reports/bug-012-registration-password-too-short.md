# БАГ-012: Регистрация с паролем менее 4 символов

| Поле | Значение |
|------|----------|
| **ID** | BUG-012 |
| **Название** | Регистрация с паролем менее 4 символов |
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Окружение** | Windows 11, Яндекс Браузер 26.6.0.0 (WebKit 537.36) |
| **Компонент** | Регистрация |
| **Шаги воспроизведения** | 1. Открыть Demoblaze (https://www.demoblaze.com/)<br>2. Нажать кнопку "Sign up" в верхнем меню<br>3. В поле "Username" ввести валидный логин <br>4. В поле "Password" ввести короткий пароль до 4-х символов <br>5. Нажать кнопку "Sign up" |
| **Фактический результат** | Регистрация успешна, появляется Alert с сообщением "Sign up successful" |
| **Ожидаемый результат** | Система выдает сообщение об ошибке: "Пароль должен содержать не менее 4 символов" |
