# Тестирование Demoblaze

## О проекте
Этот репозиторий содержит результаты тестирования веб-сайта **Demoblaze** — учебного интернет-магазина. Проект выполнен в рамках портфолио для позиции **тестировщик ПО (ручное и API-тестирование)**.

## 🎯 Цель проекта
- Продемонстрировать навыки **ручного тестирования** (составление чек-листов, тест-кейсов, баг-репортов).
- Показать умение работать с **API** (Postman, анализ запросов через DevTools).

## 🛠 Используемые инструменты
| Инструмент | Назначение |
|------------|------------|
| **Postman** | API-тестирование, создание коллекции запросов |
| **DevTools** | Перехват и анализ сетевых запросов |
| **Markdown** | Оформление документации |
| **GitHub** | Хранение и демонстрация портфолио |
| **Яндекс Браузер** | Ручное тестирование UI |

## 🔍 Анализ API Demoblaze
В ходе работы были выявлены особенности тестируемого API:
- Все эндпоинты используют метод **POST**
- API всегда возвращает статус **200 OK**, даже при ошибках
